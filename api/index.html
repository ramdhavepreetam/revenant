API Reference¶

Module-level documentation generated from source docstrings via mkdocstrings. Modules live under core/, tts/, and apps/ (flat, added to the import path in mkdocs.yml).

core — LLM, routing, memory¶

Module What it does
local_llm_writer ChatConfig, call_model, stream_model — the local LLM call layer (Ollama + OpenAI-compatible) and the CLI.
agent_router Task-based multi-model routing: classify, config_for_role, warm_role. See Model Routing.
agent_tools Revenant harness: Tool + ToolRegistry (tool schema, prompt docs, dispatch).
agent_protocol Revenant harness: dual tool-call protocol — render_system_block, parse_action.
agent_fs_tools Revenant: read-only, path-confined fs tools (read_file, list_dir, glob, grep).
agent_edit_tools Revenant: mutating, approval-gated write_file / edit_file (path-confined).
agent_bash_tool Revenant: run_bash (approval-gated; destructive-command footgun block).
agent_companion_tools Revenant companion front-end: memory_search / memory_save / set_reminder (boundary-gated).
agent_capacity Hardware/model detection → loop-knob recommendations (recommend, detect_machine).
agent_native_tools Native tool-calling detection per model (supports_native_tools, probe-once cache).
agent_loop Revenant: the AgentLoop engine (call → parse → approve → dispatch → observe → repeat).
aibot_context Token-budgeted context assembly, memory ranking, sentence buffering.
aibot_summary Rolling session summarization with a small factual model.
aibot_profiles Model/style/companion profiles + model_roles; profile resolution.
aibot_storage SQLite conversation store (source of truth), summaries, episodes.
aibot_personal_memory Structured personal-memory learning + human-gated approval.
aibot_memory Local semantic recall (vector index adapter).
aibot_companion_memory Per-companion memory store.
aibot_companion_compiler Compiles a plain-language companion brief into a system block.

tts — voice¶

Module What it does
aibot_tts TTS dispatch layer behind /api/tts.

apps — servers¶

Module What it does
web_app Core request handler (LocalUIHandler): the turn pipeline, routing integration, all API routes.
agent_cli The revenant coding-agent CLI entry point.

Note

Some older modules still lack module-level docstrings; their public functions and classes are documented where docstrings exist. Docstrings are added opportunistically as modules are touched.
